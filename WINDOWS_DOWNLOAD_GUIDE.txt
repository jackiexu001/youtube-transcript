YouTube Transcript · Windows 安装说明

1. 下载 YouTube-Caption-Archive-2.2.0-Windows-x64-Setup.exe。
2. 双击安装程序，按向导完成安装。
3. 从开始菜单打开“YouTube Transcript”。
4. 粘贴 YouTube 博主主页，填写本次抓取数量；如需为无字幕视频生成 AI 字幕，请选择 Groq 或 OpenAI 并输入对应 API Key。
5. 点击“开始抓取”。
6. 字幕档案默认保存到“文档\YouTube 字幕学习档案”，可在应用中更换位置。

发布版已包含运行程序和 yt-dlp，不需要安装 Python，也不会下载 YouTube 视频文件。
当前免费版本没有 Windows 商业代码签名，首次安装可能显示 Microsoft Defender SmartScreen 提醒。请只从官方网站下载，并用随附的 .sha256 文件核对安装包完整性。
