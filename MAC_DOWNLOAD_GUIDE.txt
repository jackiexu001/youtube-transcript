YouTube Transcript｜macOS 免费版

安装：
1. 把“YouTube Transcript.app”拖到旁边的 Applications 文件夹。
2. 到“应用程序”中打开它。

由于当前免费版本没有购买 Apple Developer 会员和公证，macOS 第一次可能阻止打开：
1. 在 Finder 中按住 Control 点按应用，选择“打开”。
2. 如果仍被阻止，打开“系统设置 → 隐私与安全性”。
3. 在页面底部找到这款应用，点击“仍要打开”。

使用：
1. 粘贴 YouTube 博主主页，例如 https://www.youtube.com/@xxxx
2. 输入本次抓取数量；0 表示全部，大频道建议每次 50–100 条。
3. 如需为无字幕视频生成 AI 字幕，请选择 Groq 或 OpenAI 并输入对应 API Key；密钥会分别保存在 macOS 钥匙串中。界面的“获取 API Key”可打开官方申请页面。
4. 选择字幕学习档案保存位置，然后点击“开始抓取”。
5. 再次输入同一频道时，会自动跳过已完成的视频并继续更新。

隐私与空间：
- 不下载 YouTube 视频文件。
- 只在你选择的本地文件夹保存 HTML、字幕、公开元数据和 CSV。
- 播放视频时需要联网，并通过仅限本机的 127.0.0.1 服务打开档案。
